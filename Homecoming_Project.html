Homecoming College Project

Homecoming was a small game made with Unreal Engine 4; it was a small assignment where we were tasked with creating some sort of project using only one button. For this task, we decided to create a small game within a month, with the game taking five to ten minutes to complete. This was a four-person project, and we had a well-balanced team: one person was good at art, another focused on sound, I handled game and level design, and the other person took on the role of project lead.

The project was inspired by games such as Inside and Limbo. From the beginning, this game was planned to be a 2D sidescroller so that the player will be tasked with jumping over obstacles on their way to the end to complete the game, with their goal of timing jumps over any obstacles. One feature I added to the game was for the player's character to begin running automatically once the game starts and to never stop running.

The story for this game started out as the player character playing as a little boy lost in the woods where the games background was coloured black and grey with somber music playing. As the player gets closer to home the colours will change to brighter and happier ones with the music becoming more happier with it. Due to time constraints and running into difficulty with the 2D character we settled on a free 2D sprite of an old wizard, which in turn the story changed to being about an old wizard returning home from an adventure.

Project Design Goals

  • Create a fun game in UE4.
  • Demonstrate skills in level & game design.
  • Create an interesting game world and tell a compelling story based on the default UE4 assets.
  • Make a short 2D game with the use of only one button.

What I added to the game:

    • Added the 2D sprite to the game...(With some difficulty)
    • I put in a script for every time the player is successful in avoiding the obstacle the characters speed will increase slightly every time they land after the obstacle.
